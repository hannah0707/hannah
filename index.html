📖 填写说明：去哪创建 Key · 每一项填什么 · 怎么测试 · 怎么更换 / 删除

一、去哪里创建 API Key（以常见平台为例）

  • DeepSeek：登录 platform.deepseek.com → API Keys → 新建，复制保存（只显示一次）。
  • Kimi（Moonshot）：登录 platform.moonshot.cn → API Key 管理 → 新建。
  • 通义千问（DashScope / 百炼）：登录 阿里云百炼 → 创建 API Key。
  • 其他 OpenAI 兼容平台同理，在其控制台创建 Key。

二、每一项填什么

  • 平台名称：随便填，仅作备注（如「我的 DeepSeek」）。
  • 模型名称：填该平台的具体模型 ID，例如 deepseek-v4-flash、kimi-k3、qwen-plus。
  • API 地址：填完整的对话接口地址，必须以 https:// 开头、以 /chat/completions 结尾：
    • DeepSeek：https://api.deepseek.com/chat/completions
    • Kimi：https://api.moonshot.cn/v1/chat/completions
    • 通义千问：https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions
  • API Key：粘贴你创建的 Key。默认隐藏；留空表示「沿用已保存的 Key，不改动」。

三、怎样测试连接

  • 填好后点「💾 保存配置」，再点「🔌 测试连接」。会向你的地址发一条极小的测试请求。
  • 成功会提示「✅ 连接成功」；失败会给出不含 Key 的原因（如地址错误、Key 无效、余额不足、或被跨域拦截）。

四、怎样更换或删除 Key

  • 更换：重新粘贴新 Key 到输入框，点「保存配置」即可覆盖。旧 Key 立即失效（请先到平台控制台吊销旧 Key）。
  • 删除：点「🗑 清除配置」，会清空本机保存的平台 / 模型 / 地址 / Key（仅本地，不影响平台账户）。

🔒 若某平台不允许网页直接调用（浏览器报跨域 / CORS 错误），说明它不适合纯前端直连。此时请勿把 Key 交给任何「中转」网页，更安全的做法是使用一个你自己的后端代理（几行 Node/Python 即可，Key 只留在服务端）。本工具会如实报错，不会假装连接成功。
